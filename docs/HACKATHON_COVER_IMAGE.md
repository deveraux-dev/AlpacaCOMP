## Judge-Facing Intent

The cover is designed as a small gallery card, not a poster full of detail.

Primary message:

> AI can suggest. Code decides.

What a judge should understand in 3 seconds:

- This is an AI trading project.
- The core idea is safety before execution.
- Unsafe orders are refused before Alpaca is reached.
- The visual identity matches the README, deck, and proof portal.

## Upload Guidance

- Upload `13forge-lablab-cover-final.png`.
- Keep the full 16:9 crop if Lablab allows manual positioning.
- If the platform crops the image, keep the left headline and right REFUSED stamp visible.
- Do not use a screenshot-heavy cover; screenshots belong inside the README, deck, and demo.

## Reusable Cover Prompt

Use this prompt only if the cover needs to be regenerated in another design tool:

```text
Create a 16:9 Lablab.ai hackathon project cover for 13forge, an AI trading safety layer for Alpaca.

The image must work as a small grid-gallery thumbnail. Use big readable shapes, high contrast, and minimal text. Match the 13forge visual identity: dark black grid background, white typography, green proof/check accents, and red refusal/blocking accents.

Main text must be exact and large:
"AI can suggest. Code decides."

Include the 13forge logo in the upper left. Add a clear red REFUSED stamp on the right with "Broker not reached" and "$2,525 > $2,000 limit". Show a simple visual flow along the bottom: "AI idea: Suggests" -> "Rust gates: Check" -> "Alpaca: Blocked".

Do not include tiny code snippets, fake stock charts, robots, generic Wall Street imagery, dense UI screenshots, or unsupported claims like guaranteed safety. Keep all important content padded away from the edges.
```

## Acceptance Check

- The title is readable at 360px wide.
- The red REFUSED stamp is visible at thumbnail size.
- No text overlaps.
- The image feels like the same product family as the README, deck, and portal.
